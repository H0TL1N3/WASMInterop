WASMInterop

This is the home page for the front-end of the WASMInterop project. Select the benchmark you wish to test in the navbar above.

Each test will have four ways to run it:

  1. Clent-side (JS)
  2. Client-side (WASM)
  3. Server-side (Python)
  4. Server-side (WASM)
For each test, the "result" and "execution time" metrics will be provided. For Client-side runs, it will be recorded via the Performance API. For Server-side runs, it will be sent with the reply and recorded via time.
